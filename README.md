# 🐍 Python Fundamentals & Codewars Challenges

This repository serves as a collection of solutions to fundamental programming problems and popular challenges, primarily sourced from platforms like **Codewars**. The goal is to practice, solidify, and demonstrate mastery of core Python syntax, data structures, and algorithmic thinking.

## ✨ Why This Repository?

  * **Foundation Practice:** Focuses on essential Python features (loops, conditionals, functions, data types, list comprehensions, etc.).
  * **Algorithmic Thinking:** Provides solutions to common logic puzzles and small algorithms.
  * **Reference:** Acts as a quick reference for clean, efficient Python solutions to well-known problems.

## 📂 Repository Structure

Each file typically corresponds to a single programming challenge. Files are named to reflect the problem they solve, often including the **Kyu Rank** from Codewars (if applicable) for difficulty sorting.


## 🎯 Python Fundamentals Covered

The solutions in this repository demonstrate the application of:

  * **Data Structures:** Lists, Dictionaries, Sets, and Tuples.
  * **Control Flow:** `if/elif/else`, `for` loops, and `while` loops.
  * **String Manipulation:** Slicing, methods (`.split()`, `.join()`, `.strip()`), and f-strings.
  * **List Comprehensions:** Concise creation of lists.
  * **Functions:** Defining and calling functions with various arguments and return types.
  * **Basic Recursion:** Solving problems by calling the function within itself.

## ⚙️ How to Run the Solutions

To test any of the solutions locally:

1.  **Clone the Repository:**

    ```bash
    git clone https://github.com/YourUsername/python-fundamentals.git
    cd python-fundamentals
    ```

2.  **Run a Specific File:**
    Navigate to the directory containing the file and run it using the Python interpreter. (Note: Many files include example function calls at the bottom, often inside an `if __name__ == "__main__":` block).

    ```bash
    # Example for a 7kyu problem
    python 7kyu/isograms.py
    ```

## 🤝 Contributing

Contributions are highly welcome\! Whether it's submitting a solution to a new challenge, optimizing an existing solution, or fixing a bug, your help is appreciated.

### Submission Guidelines

1.  **Fork** the repository.
2.  **Create a branch** for your feature or fix (e.g., `git checkout -b feature/add-5kyu-challenge`).
3.  **Add your solution** to the appropriate difficulty directory (e.g., `5kyu/`).
      * **File Naming:** Use `snake_case` (e.g., `mumbling.py`).
      * **Best Practice:** Include the original problem description or a link to the Codewars challenge in a docstring at the top of your file.
      * **Testing:** Include a simple test or function call at the bottom of your file to demonstrate that the code works.
4.  **Commit** your changes (`git commit -m 'Add 5kyu solution for Mumbling'`).
5.  **Push** to your branch (`git push origin feature/add-5kyu-challenge`).
6.  **Open a Pull Request** to the `main` branch of this repository.
